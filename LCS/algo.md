# 準備
## 概要
２つの文字列S,Tの最長共通部分列(LCS)を求める。この問題は部分構造最適性を持つので、動的計画法で解ける。dpは以下のように定義する。
```math
dp[i][j] = \text{文字列Sのi文字目までと文字列Tのj文字目までの最長共通部分列}
```

## 最後の文字が同一の時
それぞれの要素から最後の要素を取り除いた列の最長共通部分列を見つけ、その最長共通部分列に取り除かれた要素を追加すれば良い。

>例として、文字列S：「BANANA」と文字列T：「ATANA」をを考える。共通する最終要素を取り除くことを、共通する最終要素がなくなるまで繰り返す。取り除かれる文字列は「ANA」である。残された文字列はS：「BAN」、T：「AT」であり、これらの最長共通部分列は「A」である。取り出した要素を追加すると、「AANA」となり、これが元の文字列の最長共通部分列である。

これを数式で表すと、
```math
\text{if}\quad S_n = T_m, \quad\text{then}\quad LCS(S_n, T_m) = LCS(S_{n-1}, T_{m-1})
```

## 最後の文字が同一でない時
$S_n$と$T_m$の最長共通部分列は、LCS（$S_n$, $T_{m-1}$）とLCS（$S_{n-1}$, $T_m$）の長い方である。

>この特性を説明するために、以下の例を考える。<br>
文字列S：ABCDEFG<br>
文字列T：BCDGK<br>
これら２つの文字列の最長共通部分列は、最後が「G」（文字列Sの最後の要素）か、そうではないかのどちらかである。

### 最長共通部分列の最後が「G」である場合
この場合、最長共通部分列の最後が「K」（もう一方の文字列Tの最後の文字）であることはない。したがって、文字列Tから末尾の「K」を削除したものと、文字列Sの最長共通文字列は、元の文字列同士の最長共通文字列と同一である。<br>
つまり、
```math
LCS(S_n, T_m)=LSC(S_n, T_{m-1})
```

### 最長共通部分列の最後が「G」ではない場合
この場合、最長共通部分列の最後が「G」であることはない。したがって、文字列Sから末尾の「G」を削除したものと、文字列Tの最長共通部分列は、元の文字列同士の最長最長共通部分列と同一である<br>
つまり、
```math
LCS(S_n, T_m)=LSC(S_{n-1}, T_m)
```
